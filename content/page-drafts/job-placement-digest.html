04 · How I debug

Debugging proof: a request log that silently under-reported

Signal

Codex provider generations never appeared in the WordPress AI request log. Nothing errored; the diagnostic silently looked complete.

Diagnosis

Logging decorated one SDK HTTP transporter. Supported providers using a sidecar, custom handler, or direct WordPress HTTP request bypassed that boundary and disappeared from the record.

Constraint

Lifecycle-hook capture restored the missing success rows in integration testing, but it double-logged successes when the provider bridge remained active and still omitted failures. Capture, attribution, and ownership cannot be collapsed into a one-line fix.

Result

I own the report and the integration testing; another contributor owns the fix. That split is the honest one, and it is not the first time it has held.

05 · What prevention looks like

The constraint is narrower than the slogan

Within the standard block-editor controls this theme governs, authors cannot introduce arbitrary colors, gradients, font sizes, or spacing. Those choices resolve to a named token vocabulary in theme.json. Custom code and database-owned content remain governed through review, snapshots, and verification.

A recurring class of palette-review work moves from manual enforcement into the authoring system. That does not make drift impossible everywhere; it makes the governed editor choices explicit, testable, and cheaper to change.
